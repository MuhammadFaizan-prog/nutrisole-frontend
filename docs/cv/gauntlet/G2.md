# G2: gauntlet iteration 2 (2026-10-12, Kaggle T4 for training + CPU sandbox for eval)

Training: Kaggle free T4 (detectors, 224 px classifier) and sandbox CPU (192 px classifier, ablation). **All evaluation, latency and gauntlet numbers: sandbox CPU, 2 cores aarch64, onnxruntime.** This is not a phone and not an emulator. Some later gauntlet runs shared the CPU with another job (load average around 10), and those runs show higher latency and more dropped frames; they are flagged below.
Proof level is unchanged from G1: level 4 (validated on a public locked test) for the classifier only. The detector is still below usable.

## What changed vs G1
- **Detector data det-v2** = det-v1 (LVIS F&V, 9/12 classes, same locked test 557 / test_rf 149) + COCO background negatives (train/val/neg_test split). Open Images was blocked here (HTTP 403), so the class count stays 9/12. A Kaggle-side OIV7 extraction is in progress for G3.
- **Detectors trained on GPU**: yolo26n and yolo11n, with identical settings (640 px, 150 ep max, patience 30, cos LR, close_mosaic 15). yolo26n early-stopped at ep 89 (best ep 59). yolo11n stopped at ep 95 (best ep 65). Val mAP50 at 640 was 0.300 and 0.304. Each kernel's post-train eval crashed on a relative test_rf path; the weights are intact and all eval was redone locally. The kernel template is patched.
- **CPU ablation**: yolo26n 320, freeze-10. Stopped after 7/12 epochs (about 9.5 min/epoch, sandbox restarts) and evaluated from last.pt.
- **Quality classifier**: trained on quality2-g2aug (TRAIN copies with phone-camera augs: low light, noise, WB, blur, JPEG). There are two runs: CPU 192 px with the G1 recipe, and a Kaggle 224 px run (60 ep, batch 128).
- **Measurement v0.3 + rubric v0.2**: shadow/chroma surface mask (ring 0.3, shadow chroma 16), dark-defect rel_drop 30 with chroma gate 25. New `measurementAgreement.pRottenMin = 0.05`: a measurement-only C/Reject now needs the classifier to agree. All of this was tuned on VAL only (`ml/grading/tune_v2.py --write`). The rubric JSON and TS `RUBRIC` were updated together, which fixes the known `rules.ts` break.
- **Tracker defaults**: scoreAlpha 0.35 -> 0.2, set in both `ml/eval/tracker.py` and `native/src/cv/pipeline/tracker.ts`, and the parity fixture was regenerated. Evidence from DEV clips (VAL images): G1 detector static flicker went 2.375 -> 1.125 /10s with no loss in segment accuracy, TTFC or false alarms. On the G2 detector the grid optimum ties the defaults (0.25 /10s), and the tie-break picks scoreAlpha 0.2.
- **New negative test clip** (g2clips_negtest, 2.7 min, COCO neg_test + plain backgrounds).

## Promotion decision: **G1 detector stays champion; no G2 detector promoted.**
The rule was: promote only if better on test_rf AND the gauntlet, with no per-class regression above 1 pt.
- yolo11n@480 beats G1 on test_rf (0.375 vs 0.323) and on test (0.315 vs 0.125). It is worse on gauntlet det segment accuracy (58.3 vs 62.5%) and on false alarms (42.5 vs 3.75 /min), and it regresses lemon_lime (-13 pts) and apple (-2 pts) on test_rf. **Not promoted.**
- yolo26n@384 is not better on test_rf (0.324 vs 0.323 NMS / 0.308 one2one is within noise). The gauntlet is worse (50% segments, 136 FA/min), and citrus and lemon_lime regress. **Not promoted.**
- **Classifier**: the G2 192 model improves acc and low-light, but crop rotten recall drops 0.983 -> 0.941 and tube-light rotten recall drops 0.966 -> 0.941. **Not promoted** as champion; it stays the G2 candidate. The safety-relevant metric (rotten on crops) regressed.
- **Promoted (code defaults)**: measure v0.3 + rubric v0.2-g2 (agreement gate 0.05) and tracker scoreAlpha 0.2. Both were tuned on VAL/DEV only. The TEST proxy with the G1 classifier is 0.669 -> 0.978.

## Top 3 failure modes -> G3 (details: G2_failures.md, plan: G2_next.md)
1. **Detector data ceiling.** LVIS crowded scenes with incomplete (federated) labels: 67% of test GT boxes are missed (banana 3471/5048). lemon_lime and citrus confuse each other (86 swaps). cucumber and capsicum are at about 0.1 or below. 3 classes are missing. GPU training doubled test mAP but did not move the photo-like test_rf at deploy sizes.
2. **False alarms on clutter.** Repetitive red/round textures (stadium seats -> tomato) and plain backgrounds. The G2 detectors are more confident on textures than G1: 5-6 FA/min on the new negtest and 42-136/min on the G1 neg clip.
3. **Classifier crop/lighting gap.** The classifier is trained on full Sultana frames, so rotten recall falls on detector-style crops (0.941) and under tube light (0.941). Guava rotten is the worst class. The 224 Kaggle run underfit/overfit (0.948).
